# Anime Run — Endless Runner

## Run it in VS Code
1. Extract `Anime_Run_Game.zip`.
2. Open the extracted `anime_run_game` folder in VS Code.
3. Open `index.html` in a browser. Recommended: install the **Live Server** extension, right-click `index.html`, then choose **Open with Live Server**.
4. Pick one of the four original starter heroes and press **Start Running**.

## Controls
- Left / Right arrows or A / D: change lane
- Space / Up arrow / W: jump
- Escape: pause/resume
- On mobile: use the on-screen buttons or swipe left/right/up on the game canvas

## Files
- `index.html`: page and menus
- `style.css`: layout and visual styling
- `game.js`: canvas rendering, movement, coins, obstacles, scoring and local best score

This starter uses original simple canvas-drawn anime-style characters, not downloaded character artwork. Best score is saved in browser localStorage. The sound toggle is a placeholder; no audio assets are included yet.
